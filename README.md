Data Communication & Networking Lab
​This repository contains various network topologies and configurations developed using Cisco Packet Tracer. It covers fundamental and advanced networking concepts, ranging from basic connectivity to complex routing and security protocols.
​🚀 Key Configurations Included
​1. Routing Protocols
​Static Routing: Manual path configuration for small-scale networks.
​RIP (Routing Information Protocol): Distance-vector routing implementation.
​OSPF (Open Shortest Path First): Link-state routing for scalable networks.
​BGP (Border Gateway Protocol): Configuration for external routing between autonomous systems.
​2. Switching & VLANs
​VLAN with Trunking: Segmenting the network into logical groups and allowing communication across multiple switches.
​MAC Address Learning: Understanding how switches use ARP to map MAC addresses.
​3. Network Services & Security
​Firewall Setup: Implementing basic security rules to filter traffic.
​DHCP & DNS: Automated IP addressing and domain name resolution within a topology.
​IoT Implementation: Integrating smart devices into the network.
​🛠️ Tools Used
​Cisco Packet Tracer: For designing and simulating network environments.
​CLI (Command Line Interface): All configurations are done via router/switch console commands.
​📁 Repository Structure
​Files ending in .pkt can be opened and simulated in Cisco Packet Tracer.
